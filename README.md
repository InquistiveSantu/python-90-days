# Python 90 Days – From Zero to Software Engineer

A structured 90-day journey to master Python fundamentals, develop logical thinking, improve problem-solving skills, and prepare for Python Software Engineering roles.

## Learning Objectives

- Build strong Python fundamentals from scratch.
- Understand programming concepts deeply.
- Develop independent problem-solving abilities.
- Learn patterns, dry runs, debugging and code execution.
- Practise object-oriented programming.
- Learn SQL, PostgreSQL and FastAPI.
- Build practical software engineering projects.

## Daily Learning Method

1. Understand the concept.
2. Study practical examples.
3. Identify the problem-solving approach.
4. Write pseudocode.
5. Perform a dry run.
6. Implement Python code.
7. Test and debug.
8. Document mistakes and learnings.

## Learning Roadmap

| Phase | Duration | Focus |
|---|---|---|
| Phase 1 | Month 1 | Python Fundamentals |
| Phase 2 | Month 2 | Intermediate Python |
| Phase 3 | Month 3 | Problem Solving and Projects |

## Daily Commitment

- Study time: 1 hour
- Theory: 20%
- Hands-on coding: 65%
- Revision: 15%

## Long-Term Goal

Become a skilled Software Engineer and progress towards a Forward Deployed Engineer (FDE) role within three years.

**Consistency over motivation. Learn, practise, build and improve every day.**
